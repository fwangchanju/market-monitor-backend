# 테스트 기준

## 이 문서가 필요한 이유

사용자는 코드를 직접 읽지 않는다. 그래서 **테스트가 코드 리뷰의 대체재**다.

"동작한다"를 증명하는 수단이 테스트밖에 없으므로, 무엇을 테스트하고 무엇을 안 하는지가 곧 **안전망의
크기**를 정한다. 이 문서는 그 경계를 정한다.

---

## 반드시 테스트한다

- **순수 계산·판정 로직** — 집계, 평균, 정렬, 순위 부여, 시간대 판정, 파싱, 텍스트 생성
- **조건 분기가 있는 서비스 로직** — 분기가 2개 이상이면 각 분기를 덮는다
- **경계 조건** — 빈 컬렉션, null, 0, 부호가 바뀌는 지점, 날짜 경계(주말·장 마감 시각)
- **버그를 고친 자리** — 재발 방지. 고치기 전에 실패하는 테스트를 먼저 만드는 것을 우선한다

## 테스트하지 않는다

- 단순 위임 메서드 (`return service.doSomething(x)` 한 줄짜리)
- 엔티티 getter/setter, record 접근자
- 외부 API 호출 자체 (키움·텔레그램·렌더러) — 네트워크에 의존하는 건 매뉴얼 테스트로 뺀다
- 프레임워크가 보장하는 것 (Spring DI 배선, JPA 매핑 자체)
- 설정 파일 값

---

## 테스트 종류

### 단위 테스트 — 기본

**DB도 Spring 컨텍스트도 없이 도는 것을 기본으로 한다.** Mockito로 협력 객체를 대체한다.

CI가 DB 없이 돌아야 하므로 이게 기본값이어야 한다. 기존 `MarketMapCategoryServiceTest`,
`MarketMapCategoryTreeServiceTest`가 이 형태다.

### Spring 컨텍스트 테스트 — 꼭 필요할 때만

`@SpringBootTest`는 느리고 DB를 요구한다. **배선 자체를 검증해야 하는 경우가 아니면 쓰지 않는다.**

### 매뉴얼 테스트 — 일반 테스트에서 분리

실제 외부 API를 호출하거나 실제 텔레그램 메시지를 보내는 테스트다. 배포 후 수동 확인용이다.

- `@Tag("manual")`을 붙인다
- `test` 태스크에서 제외한다 (`excludeTags 'manual'`)
- CI에서 돌지 않는다
- Javadoc에 **실행 조건과 실행 명령**을 적는다

이 분리가 없으면 누군가 `./gradlew build`를 쳤을 때 실 API가 호출되고 실 알림이 나간다.

---

## 테스트 가능한 코드를 위한 제약

테스트가 불가능하게 만드는 패턴은 **프로덕션 코드 쪽을 고친다.** 테스트를 포기하지 않는다.

### 현재 시각

`LocalDateTime.now()`를 메서드 안에서 직접 부르면 그 코드는 테스트할 수 없다. 시각에 따라 동작이
갈리는 코드는 **시각을 주입받는다.**

- 인자로 받거나
- `java.time.Clock`을 주입받는다

`CollectionChecker`가 이 문제로 테스트가 막혀 있던 대표 사례다.

### 무작위·외부 상태

난수, 파일 시스템, 네트워크에 직접 의존하지 않는다. 경계 밖으로 밀어낸다.

## 작성 규칙

- 파일명은 `<대상클래스>Test`
- 테스트 메서드명은 **무엇을 검증하는지 한국어로 서술**한다. `@DisplayName`을 쓰거나 메서드명 자체를
  서술형으로 한다
- 하나의 테스트는 하나를 검증한다. assert가 여러 개여도 좋지만 검증 대상은 하나여야 한다
- given / when / then 구분이 드러나게 쓴다
- 단언은 AssertJ(`assertThat`)를 쓴다

## 무엇을 assert 하는가

- **결과값**을 확인한다. "예외 없이 끝났다"만 확인하는 테스트는 의미가 없다
- 협력 객체 호출 여부(`verify`)는 **그 호출 자체가 목적인 경우에만** 쓴다. 저장·발송처럼 부수효과가
  본질인 로직이 여기 해당한다
- 내부 구현이 아니라 **관찰 가능한 동작**을 검증한다. 리팩터링했다고 깨지는 테스트는 잘못 짠 것이다

---

## 커버리지

수치 목표는 두지 않는다. "반드시 테스트한다" 목록을 덮었는지로 판단한다.

숫자를 목표로 잡으면 getter 테스트 같은 무의미한 테스트가 늘어나고, 정작 분기가 복잡한 곳은 그대로
남는다.
